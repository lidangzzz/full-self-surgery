# SofaRobotAI 场景手册（69 个手术场景全目录）

> 运行方式：Unity 打开本项目 → `Assets/Scenes/MultiArmAgentScene.unity` → Play。
> 机械臂全部为 **4-5 自由度**；组织为 **SOFA FEM 软体**（原生 SofaVerseAPI 求解）；
> 针线工具挂载于机械臂 TCP，针刺力经 SOFA 碰撞球与组织真实耦合。

---

## 1. 系统总览

```
┌────────────────────────────────────────────────────────────────┐
│  MultiArmAgentManager（场景调度中枢）                            │
│    ├─ SurgicalScenario ×69（ScenarioRegistry，可热切换）          │
│    │    ├─ 旗舰场景 ×7：+liver（肝脏肿瘤）                       │
│    │    └─ 目录场景 ×62：s01…s98（参数化生成，覆盖 10 个科室）      │
│    ├─ 机械臂群：每场景 2-8 台 × 4-5 DOF（ArticulationBody）        │
│    ├─ 缝合执行器：入针→潜行→出针→拉线→收拢打结 状态机              │
│    ├─ SOFA 后端：FEM 组织 + 针尖/心跳两个耦合球 + 形变回读          │
│    ├─ 六宫格观察墙：主+前/后/左/右/顶 同时显示 + API 逐机位截图  │
│    └─ Agent API：127.0.0.1:8765（HTTP JSON，见 AGENT_API.md）     │
└────────────────────────────────────────────────────────────────┘
```

**共享底座**（所有场景复用，切换时组织镜像持续存活；2026-10-24 晚重设计为肝）：

- 组织 = **一块肝**：SOFA 六面体 FEM 网格（20×4×12，杨氏模量 3000Pa）经平滑
  形变呈现为肝——前后缘圆化、右叶向后楔形收窄、中央（走廊外）隆起增厚，
  肝红棕材质 + 胆囊（橄榄绿）+ 肝门暗带；**中央手术走廊恒等**，针-组织耦合
  与全部场景伤口几何不受影响（tear 在肝上自治缝合 4/4 验证通过）。
  Unity 侧网格每帧回读原生顶点——针压出的凹陷与心跳搏动照常可见
- 手术台：浅钢色台面 + **青绿色无菌铺巾**（中央开窗露出组织垫）+ 前缘垂帘
- 血管 = **肝上的一根血管**：单支肝血管树从肝门（前左缘暗带处）入肝，
  主干平滑 S 形贴肝表面走行（按隆起高度抬升），等间距发出分支与末梢细枝；
  始终避开中央目标走廊，右叶保持干净
- 六宫格观察墙：主视角 + 前/后/左/右/顶五个环绕摄像头，Game 视图切为
  3×2 六个大画面**同时显示**（每格边框+中文标签）；`GET /api/cameras`
  读机位位置与宫格区域，`GET /api/screenshot?camera=…` 逐机位截图，
  `camera=screen` 输出整屏合成（即视频墙本身）
- 针尖耦合球：半径 6mm，仅穿刺相位激活，罚函数接触（刚度 10）
- 心跳推压球：半径 30mm，按场景设定频率下压组织表面

**伤口基元**（每个场景二选一）：

| 基元 | 结构 | 缝合动作 |
|---|---|---|
| `Tube` 管状吻合 | 弯曲目标管道于组织中央被切断（断口暗红截面+出血池+脉冲环+箭头） | 垂直断口入针-潜行-对侧出针 |
| `Surface` 表面切口 | 组织表面线状裂伤（双侧伤口唇+出血池+脉冲环+箭头） | 跨切口入针-潜行-对侧出针 |

**机械臂角色**：`Suturer` 持针缝合（批次轮换）｜`Stabilizer` 压持组织稳定术野（心脏类场景）｜`Idle` 停靠。
每针完成：打结球 + 收拢带出现，出血池按总进度收缩；全部缝完机械臂归位。

## 2. 旗舰场景（按键 1-7 直达）

### [1] `vessel` 显微血管吻合（默认）
- **目录映射**：#3 颞浅动脉—大脑中动脉搭桥 / #21-22 断指再植 / #30 淋巴管—静脉吻合
- **组织**：粉色组织垫 + 5 根分叉血管树（216 段动静脉）
- **伤口**：主干血管（r=14mm）中央切断，9 针分 3 批
- **机械臂**：3 × 5 DOF，轮流缝合
- **看点**：血管网密布下辨认目标血管，逐针关闭断口

### [2] `heart` 不停跳冠状动脉搭桥
- **目录映射**：#34 不停跳冠状动脉搭桥术
- **组织**：深红色心外膜样组织，**心跳推压球 1.2Hz 搏动**（表面持续起伏）
- **伤口**：S 形冠状动脉（r=18mm）中央切断，4 针单臂缝合
- **机械臂**：2 × 5 DOF —— Arm_1 缝合 + Arm_2 稳定心外膜
- **看点**：运动表面上的针尖定位（放宽到位容差 20mm/驻留 0.8s）

### [3] `tendon` 屈肌腱端端修复
- **目录映射**：#25 屈肌腱二区损伤修复术
- **组织**：浅色肌腱床，白色肌腱管（r=16mm）两断端
- **伤口**：断端间隙，环形 4 针（45°/135°/225°/315° 环抱咬合）
- **机械臂**：2 × 4 DOF 轮流入针
- **看点**：管状结构环周缝合布局，兼顾强度与滑动空间

### [4] `octo` 八臂多指离断血管重建（多臂 API 编排旗舰）
- **目录映射**：#22 多指离断再植术（多组血管重建与时间分配）
- **组织**：手外科色组织垫 + 6 根分叉血管树
- **伤口**：再植血管（r=13mm，S 形走行）中央离断，**12 针分 8 批逐臂轮转**
- **机械臂**：**8 × 5 DOF**，弧形围台布局（半径 1.05m，最远臂到伤口 ≤1.18m，
  处于 5-DOF 工作空间裕度内），每臂至少一个缝合批次
- **看点**：外部 Agent 通过 API 同时接管/归位/归还全部 8 臂后，自治系统接力完成
  整台手术——`tools/eight_arm_api_demo.py` 端到端验证（17/17 通过）

### [5] `tear` 血管切开显微缝合（三段式工具臂双器械旗舰）
- **目录映射**：#1 颅内动脉瘤夹闭（血管切开与关闭）/ #3 颞浅动脉—大脑中动脉搭桥
- **组织**：手外科色组织垫 + 4 根分叉血管树
- **伤口**：r=11mm 血管**直接纵向切开**（110mm 切口缝+外翻唇+血池），4 针间断缝合
- **机械臂**：2 台**三段式工具臂**（基座回转/肩俯仰/肘俯仰三段 + 器械腕转），
  末端法兰直接安装器械、**无机械手指爪**：Arm_1 镊子（对抗牵引），
  Arm_2 持针器（夹持医用半圆弯针+缝线）
- **看点**：纯手动 API 双器械缝合——镊子夹缘对抗牵引、持针器进针-潜行-出针、
  `Cinch` 打结；实测 4/4 缝闭、无粘连不触其他组织
  （`docs/API_SUTURE_TEAR_REPORT.md`，截图 `docs/images/incised_*.png`）

### [6] `brain` 脑组织显微手术（SOFA 仿真大脑旗舰，高分辨解剖级）
- **目录映射**：#1 颅内动脉瘤夹闭 / #10 三叉神经微血管减压（脑底血管解剖）
- **大脑（SOFA FEM + 高分辨蒙皮）**：物理体为 5,280 节点六面体→四面体共旋
  FEM（保持稳定）；**渲染层为 35,120 顶点/68,698 三角形解剖级表面**——
  双半球+内侧面平坦壁（纵裂）、**多倍频脑沟回**、**Sylvius 外侧裂+中央沟**、
  颞叶隆起、小脑叶片（横行细叶）、脑干（含脑桥隆起）；每个渲染顶点绑定
  4 个最近 FEM 节点（逆距离权重）**实时蒙皮跟随 SOFA 形变**，沟回深度烘焙
  为顶点色（脑沟着色更深，自定义 Lambert 顶点色着色器）
  （**E=6kPa 灰白质混合区间、ν=0.40、质量 1.4kg**、脑干底部固定、
  重力沉降 56mm 可观测；ν=0.49 在 dt=0.02 下锁定发散，文档化取舍）
- **血管**：脑底 **Willis 环**（8 段环+双侧 ICA）+ **ACA**（中线）+
  **双侧 MCA**（外侧裂）+ **双侧 PCA**（枕后）+ 顶部软脑膜血管
- **伤口**：软脑膜血管纵向破裂，4 针（双三段式工具臂：镊子+持针器/弯针）
- **看点**：Unity 每帧回读真实 SOFA 顶点（`BrainDeformationSync`），
  六宫格视频墙全机位可见；自治缝合实测 4/4 完成
  （截图 `docs/images/brain_{top,front,screen}.png`）


### [7] `liver` 肝脏血管显微缝合（官方 SofaUnity 肝模型旗舰）
- **目录映射**：#56 活体供肝切取 / #57 小儿活体肝移植
- **肝脏（官方 SOFA demo 模型）**：直接使用 vendored SofaUnity 的经典肝网格
  **mesh/liver.msh（181 节点/596 四面体）**，经 tools/gen_liver_sofa.py 刚性
  变换到桌面（真实尺寸 0.25×0.19×0.10m，顶面 y=0.635）；**官方 FEM 参数**
  （TetrahedralCorotational E=3000 ν=0.3、DiagonalMass 密度1.0、官方固定节点
  3/39/64），MeshGmshLoader 直接加载；求解器 81-92fps@7ms
- **视觉面**：SofaUnity **liver3-HD.obj**（3,002 顶点/6,000 三角形展示模型），
  同目标盒独立变换后与 FEM 近似配准，4 节点蒙皮绑定实时跟随 SOFA 形变
- **血管**：肝门入肝右/左肝动脉主支 + 门静脉右支，肝表面走行
- **伤口**：肝被膜血管纵向切口 4 针——自治 2/4 后 API 手动接管完成
  （航点重构型 + 钳口迭代补偿），**4/4 缝闭**
- **看点**：SOFA 官方 demo 肝模型的完整集成链路（Gmsh→FEM→蒙皮→缝合）；
  截图 `docs/images/liver_official_{top,front,sutured}.png`
