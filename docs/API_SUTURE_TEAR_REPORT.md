## 2. 医用血管缝合手法（每针 7 步，全部 API 下发）

```
① MoveTip(镊子)   -> 近侧切口缘：轻夹组织缘做对抗牵引（误差 1mm）
② MoveTip(持针器) -> 进针点上方 60mm 悬停（安全接近）
③ MoveTip(持针器) -> 垂直进针：弯针尖刺入近侧缘（误差 3mm，针-组织耦合激活）
④ MoveTip(镊子)   -> 转到远侧切口缘：接应出针（误差 1mm）
⑤ MoveTip(持针器) -> 弯针弧形潜行越过切口、从远侧缘穿出（7-11mm）
⑥ Cinch(持针器)   -> 打结收针：线结+收拢带出现，血池收缩（服务端校验针尖在出针点）
⑦ MoveTip(双臂)   -> 持针器拉线抬高 + 镊子松开抬离（y≥0.60 解除耦合，无粘连）
```
