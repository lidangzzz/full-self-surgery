# API 微步血管缝合报告（DLS-IK 版）

- **时间**：2026-10-26
- **场景**：`liver`（官方 SofaUnity 肝模型，肝被膜血管切口 4 针）
- **结果**：**4/4 缝合完成，34 步 0 违规，34 帧逐步截图，9.75s 视频**

## 运动规划（全部由 API 命令驱动）

每针 8 条命令（travel→descend→pierce→through→Cinch→lift→tweez lift→下一针），
DLS-IK 伺服（2.2mm 收敛精度）驱动笛卡尔直线轨迹。

## 五重安全门禁（每命令后强制校验+截图）

| 门禁 | 规则 | 实测 |
|---|---|---|
| 步幅 | 组织内 ≤40mm | ✅ 全过 |
| 血管 | 针尖距肝动脉/门静脉/供养支 ≥6mm | **全程最近 20.5mm**（3.4 倍裕度） |
| 接触 | 针尖仅在伤口走廊内可低于肝面 | ✅ 全过 |
| 张力 | 肝 FEM 形变增量 ≤2.5mm/步 | ✅ 全过 |
| 静止 | 臂速 <0.08m/s 再下一命令 | ✅ 全过 |
