# 微动安全协议 v5 · 根因修复版（DLS-IK 伺服）

- **时间**：2026-10-25
- **场景**：`liver`（官方 SofaUnity 肝模型，肝被膜血管切口 4 针）
- **结果**：**4/4 缝合，38 步 0 违规（严格走廊 ±11mm），39 帧截图，14.25s 视频**

## 根因修复（RobotArmController.ServoToward 重写）

| 旧 Jacobian-transpose | 新 DLS-IK + 直线轨迹 |
|---|---|
| 贪心梯度 Jᵀ·e，扭曲位形停滞 | 阻尼最小二乘 Jᵀ(JJᵀ+λ²I)⁻¹·e，奇异处有界通过 |
| 稳态残差 20-25mm | **2.2mm**（提升 10 倍） |
| 小目标死区（<8mm 不动） | **4mm 微步精确跟踪**（每步实移 4.0mm） |
| 路径不可控 | 笛卡尔**直线轨迹**限速跟踪（0.04-0.14 m/s） |

## 连带根治的四个 bug

1. **FinishTask GoHome 打架**：最后一针 Cinch 后执行器把关节目标清零，
   与 API 伺服互相拉扯将针甩出 130mm → 外部收针时抑制归位
2. **HTTP 监听线程崩溃**：客户端断开→二次 Respond→未捕获异常杀线程
   （此前所有"莫名卡死"的元凶）→ 全路径防护
3. settle 窗口按飞行距离自适应（0.64m 停泊飞行需 20s+）
4. 抬针前静止预等待（quiesce），位移测量只含抬针本身
